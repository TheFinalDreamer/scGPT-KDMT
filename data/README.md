# Data

## Data Availability

The datasets used in this study are **not redistributed** with this repository due to their large file size. All data used are publicly available from standard single-cell genomics resources.

## Dataset Sources

| Dataset | Source | Approx. Cells | Cell Types |
|---------|--------|---------------|------------|
| PBMC 10X (Seurat v4) | 10x Genomics / Seurat reference | ~161,764 | 31 (celltype.l2) |
| 10X_3-rep2 | Seurat v4 R package | ~7,750 | 10 (broad types) |

## Obtaining the Data

The PBMC 10X benchmark dataset can be obtained from:
- The Seurat v4 R package (`pbmc_multimodal_2023.rds`)
- Public single-cell data portals providing h5ad-formatted PBMC reference data

## Preprocessing Workflow

This repository provides a preprocessing script that performs the following steps:

1. **Quality Control**: Filter cells by gene count, UMI count, and mitochondrial percentage
2. **Doublet Detection**: Scrublet-based doublet identification and removal
3. **Highly Variable Gene Selection**: Top 2,000 HVGs (Seurat v3 flavor)
4. **Normalization**: Library-size normalization (10,000 counts per cell) and log1p transformation
5. **Standardization**: Z-score standardization per gene
6. **Train/Validation/Test Split**: Stratified 70/15/15 split by cell type


## Example Command

```bash
# Download the PBMC 10X dataset in h5ad format (not provided by this repo)

# Preprocess
python scripts/preprocess_data.py \
  --config configs/preprocess_pbmc10x.yaml \
  --input data/raw/pbmc_seurat_v4.h5ad \
  --output outputs/processed/pbmc10x
```

The preprocessing script generates `train.npz`, `val.npz`, `test.npz`, and metadata files containing the processed expression matrices and integer-encoded labels ready for model training.
